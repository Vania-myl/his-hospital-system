## 2. 克隆 + 建库

```bash
# 1. 克隆代码
git clone https://github.com/Vania-myl/his-hospital-system.git
cd his-hospital-system

# 2. 建库灌数据（建 his 库 + 16 张表 + 岗位账号 + 基础数据）
mysql -u root -p < sql/init.sql

# 3. 改后端数据库密码（若你本机 root 密码不是 123456）
#    打开 backend/src/main/resources/application.yml，改 password 这一行即可。
#    注意：这个改动不要 commit！
```

> 数据库是**每人本地一份**，不连别人的。`application.yml` 里的 `jdbc:mysql://localhost:3306/his` 指的就是你本机的 MySQL。

## 3. 启动项目

开两个终端：

```bash
# 终端 A：后端（端口 8080）
cd backend
mvn spring-boot:run

# 终端 B：前端（端口 8081，已代理 /api 到 8080）
cd frontend
npm install
npm run serve
```

浏览器打开 **http://localhost:8081**，看到登录页即成功。

## 6. 写一个模块的套路

**照抄已经完成的挂号收费（`register/`）**，它是标准范例。

### 后端（分层：Controller → Service/Impl → Mapper → MySQL）

1. 在自己模块包下建 `controller/`、`service/`、`service/impl/`
2. Mapper 接口放 `com/his/mapper/`，XML 放 `resources/mapper/`
3. 返回体统一用 `Result<T>`（`Result.success(data)` / `Result.error(...)`）
4. 路径统一 `/api` 前缀，写操作（挂号/收费/发药等）加 `@Transactional`

```java
// 范例：com/his/register/controller/RegisterController.java
@RestController
@RequestMapping("/api/register")
public class RegisterController {
    @PostMapping
    public Result<Register> register(@RequestBody RegisterDTO dto) {
        return Result.success(registerService.register(dto));
    }
}
```

### 前端

1. 在 `api/xxx.js` 里写接口函数（仿 `api/register.js`）：
   ```js
   import service from './request'
   export function registerList(params) { return service.get('/register/list', { params }) }
   ```
2. 在 `views/xxx/` 里写 `.vue` 页面（根节点用 `class="page-card"`，风格统一）
3. 在 `router/modules/xxx.js` 里登记路由，**填对 `meta.roles`**：
   ```js
   {
     path: 'outpatient',
     name: 'Outpatient',
     component: () => import('@/views/outpatient/Outpatient.vue'),
     meta: { title: '门诊医生', icon: 'el-icon-s-cooperation', roles: ['doctor'] }
   }
   ```

## 7. 协作规范（必读）

1. **分支**：每人一个 `feature/<模块>` 分支开发，完成前先 `git pull origin main` 合并，再提 PR / 合并回 `main`。
   - WWJ：`feature/outpatient`、`feature/pharmacy`
   - HYJ：`feature/examination`、`feature/lab`、`feature/treatment`
2. **表结构同步靠 `sql/init.sql`**：谁改了表结构，必须同步改 `sql/init.sql` 并 commit；其他人 `git pull` 后重新执行 `init.sql`（会清空重建，测试数据无所谓）。
3. **密码不提交**：`application.yml` 里的数据库密码是本地环境配置，改成本机密码后不要 `git add` 这个文件。
4. **跨模块只读**：`register`、`fee_record` 是 MYL 负责，其他人**只读不写**；`medical_technology` 是 HYJ 维护、WWJ 只读；基础数据已建好，直接用。
5. **改接口先改契约**：`docs/开发契约.md` 里的接口边界是共同约定，改动前先更新文档再动代码。

## 8. 关键约定速查

- **统一返回体**：`{ "code": 200, "msg": "success", "data": {} }`，所有接口必须遵守。
- **状态码**：200 成功 / 400 参数错 / 401 未登录 / 403 无权限 / 500 服务器错；业务码 1001~1004（号源满/不可退号/不可退费/登录失败）。
- **鉴权**：登录拿 JWT，请求头带 `Authorization: Bearer <token>`；后端接口要**再次鉴权角色**，不能只靠前端隐藏菜单。
- **状态字典（全组共用）**：
  - `visit_state`：1 已挂号 / 2 医生接诊 / 3 看诊结束 / 4 已退号
  - `check_state` `inspection_state` `disposal_state`：1 已开立 / 2 已执行 / 3 已完成 / 4 已撤销
  - `drug_state`：1 已开立 / 2 已发药 / 3 已退药 / 4 已撤销
  - 金额统一 `DECIMAL(8,2)`，时间统一 `DATETIME`。
